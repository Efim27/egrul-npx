# EGRUL / EGRIP MCP

STDIO MCP-сервер на TypeScript получает сведения об организациях и индивидуальных предпринимателях по **ИНН, ОГРН или ОГРНИП**. ИНН организаций содержит 10 цифр, ИНН физических лиц и ИП — 12 цифр, ОГРН — 13 цифр, ОГРНИП — 15 цифр.[1] [2] [3]

## Настройка

Лицензионный ключ не хранится в исходном коде. Сервер читает его из обязательной переменной окружения `LICENSE_KEY`. Адрес API задан константой `API_ADDR` в `src/config.ts`.

## Подключение из GitHub

Для запуска непосредственно из репозитория в среде должен быть установлен `git`:

```json
{
  "mcpServers": {
    "egrul": {
      "command": "npx",
      "args": [
        "-y",
        "git+https://github.com/Efim27/egrul-npx.git#main"
      ],
      "env": {
        "LICENSE_KEY": "YOUR_LICENSE_KEY"
      }
    }
  }
}
```

Если в среде нет `git`, загрузите `npm pack` в GitHub Release и подключайте `.tgz` по HTTPS:

```json
{
  "mcpServers": {
    "egrul": {
      "command": "npx",
      "args": [
        "-y",
        "--package=https://github.com/Efim27/egrul-npx/releases/download/1.0.3/egrul-inn-mcp-1.0.3.tgz",
        "egrul-inn-mcp"
      ],
      "env": {
        "LICENSE_KEY": "YOUR_LICENSE_KEY"
      }
    }
  }
}
```

## MCP-инструмент

| Поле | Значение |
| --- | --- |
| Имя | `search_egrul_egrip_by_identifier` |
| Назначение | Поиск организации или ИП в ЕГРЮЛ/ЕГРИП |
| Аргумент | `identifier` |
| Тип аргумента | `string` из цифр без пробелов и разделителей |
| Поддерживаемые значения | ИНН 10/12 цифр, ОГРН 13 цифр, ОГРНИП 15 цифр |

Идентификатор намеренно передаётся строкой: это сохраняет ведущие нули и исключает проблемы числового представления. Перед запросом сервер проверяет формат, тип и контрольные разряды по опубликованным алгоритмам.[4]

Примеры аргументов:

```json
{ "identifier": "7707083893" }
```

```json
{ "identifier": "1027700132195" }
```

```json
{ "identifier": "304500116000157" }
```

Версия `1.0.3` содержит обратно несовместимое изменение: прежний инструмент `get_egrul_organization_by_inn` и аргумент `inn` заменены новым универсальным инструментом и аргументом `identifier`.

## Валидация

| Идентификатор | Проверка |
| --- | --- |
| ИНН организации | 10 цифр; контрольная цифра рассчитывается с коэффициентами `2, 4, 10, 3, 5, 9, 4, 6, 8` |
| ИНН физического лица или ИП | 12 цифр; проверяются две контрольные цифры |
| ОГРН | 13 цифр, первый разряд `1` или `5`; контрольная цифра вычисляется по модулю 11 |
| ОГРНИП | 15 цифр, первый разряд `3`; контрольная цифра вычисляется по модулю 13 |

Строки с нецифровыми символами, неподдерживаемой длиной, одними нулями или неверными контрольными цифрами отклоняются до обращения к API. ОГРН является ключевым атрибутом сведений ЕГРЮЛ, а ОГРНИП — сведений ЕГРИП.[5]

## Формат API-запроса

Сервер выполняет `POST` с `Content-Type: application/x-www-form-urlencoded`. Поле формы `identifier` содержит JSON с `ObjectCode: "DICTIONARY_CORR_EGRUL"`, `DocCode: "DICTIONARY_CORR"`, `ModeBP: "1"`, значением `LICENSE_KEY` и проверенным идентификатором в `SearchCode`.

## Локальная сборка

```bash
npm ci
npm run build
LICENSE_KEY="YOUR_LICENSE_KEY" node dist/index.js
```

STDIO-сервер ожидает MCP-сообщения в `stdin`. Служебные сообщения направляются только в `stderr`, чтобы не повреждать протокольный поток `stdout`.
